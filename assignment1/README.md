# Assignment 1 - Portfolio Website

## Project: Personal Portfolio

A clean and modern portfolio website showcasing projects, skills, and contact information.

---

## 📁 Files:
- `portfolio.html` - Main portfolio page
- `portfolio.css` - Styling for the portfolio
- `output.html` - Simple page to paste screenshot

---

## 🎨 Features:

### Design:
- ✅ Beautiful gradient background (purple-blue)
- ✅ Sticky navigation header
- ✅ Hero section with introduction
- ✅ Projects showcase with 4 cards
- ✅ About section with skills badges
- ✅ Contact section with email link
- ✅ Professional footer

### Technical:
- ✅ CSS Variables for consistent design
- ✅ Responsive layout
- ✅ Hover effects on cards and navigation
- ✅ Golden accent color with purple gradient
- ✅ Clean semantic HTML structure

---

## 🎯 CSS Features Used:

- **Colors:** Purple-blue gradient background (#667eea to #764ba2)
- **Accent Color:** Golden yellow (#ffd700)
- **Layout:** Flexbox for navigation and sections
- **Cards:** White cards with glassmorphism effect
- **Typography:** Segoe UI font family
- **Effects:** Smooth transitions and hover animations
