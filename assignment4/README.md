# Assignment 4 - Styled Portfolio

## Design Choices Documentation

### 🎨 **Color Palette Rationale**

I chose a **professional yet modern** color scheme with 5 carefully selected colors:

1. **Primary Color (#2d3748 - Dark Navy)**: Represents professionalism and trust. Used for headings and important text to establish hierarchy.

2. **Secondary Color (#4a5568 - Medium Gray)**: Provides excellent readability for body text without being too harsh like pure black.

3. **Accent Color (#667eea - Soft Purple)**: Adds a creative and modern touch. Purple is associated with creativity and innovation, perfect for a developer portfolio. Used for CTAs and highlights.

4. **Background Color (#f7fafc - Light Gray)**: Provides a soft, easy-on-the-eyes background that doesn't compete with content. Better than pure white for extended reading.

5. **White (#ffffff)**: Used for cards and contrast elements to create visual breathing room.

**Why this combination?**
- High contrast for accessibility
- Not too vibrant (professional)
- Purple adds personality without being overwhelming
- Gray tones are easy on eyes

---

### ✍️ **Font Pairing Strategy**

**Heading Font: Playfair Display (Serif)**
- Elegant and classic
- Creates visual hierarchy
- Adds sophistication and personality
- Great for portfolio headings

**Body Font: Inter (Sans-serif)**
- Modern and highly readable
- Clean lines perfect for body text
- Excellent at all sizes
- Professional appearance

**Why this pairing?**
The combination of serif headings with sans-serif body creates **visual contrast** and **hierarchy**. Playfair Display adds elegance while Inter ensures readability. This is a tried-and-tested combination used by many professional websites.

---

### 🎯 **Design Principles Applied**

1. **Consistency**: Used CSS variables for consistent spacing, colors, and typography throughout
2. **Hierarchy**: Clear visual distinction between headings, subheadings, and body text
3. **Whitespace**: Generous spacing makes content breathable and easy to scan
4. **Responsiveness**: Mobile-first approach ensures good experience on all devices
5. **Interactivity**: Hover effects provide feedback and make the site feel alive

---

### 💡 **CSS Variables Benefits**

Using `:root` variables makes it easy to:
- Maintain consistent design system
- Quickly update entire color scheme
- Ensure spacing follows a predictable scale
- Make the code more maintainable

---

### 📱 **Responsive Approach**

The design adapts gracefully to smaller screens by:
- Reducing font sizes appropriately
- Stacking grid layouts vertically
- Adjusting navigation for mobile
- Maintaining readability at all viewport sizes
