# Assignment 6 - Flexbox Practice

## Files Created:

### 1. **menu.html**
- Horizontal menu bar using `display: flex`
- Uses: `justify-content: center`, `align-items: center`, `gap`

### 2. **login.html**
- Login form perfectly centered (horizontally & vertically)
- Uses: `justify-content: center`, `align-items: center`, `flex-direction: column`

### 3. **products.html**
- 8 product cards in a responsive grid
- Uses: `flex-wrap: wrap`, `gap`, `justify-content: center`

### 4. **navbar-hero.html**
- Navbar with logo on left, links on right
- Hero section with centered content
- Uses: `justify-content: space-between`, `align-items: center`, `flex-direction: column`

## Flexbox Properties Used:

- ✅ `display: flex`
- ✅ `justify-content` (center, space-between)
- ✅ `align-items` (center)
- ✅ `flex-direction` (column)
- ✅ `flex-wrap` (wrap)
- ✅ `gap`
- ✅ Proper centering techniques
