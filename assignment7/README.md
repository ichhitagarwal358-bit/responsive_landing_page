# Assignment 7 - CSS Grid Layouts

## Files Created:

### 1. **gallery.html** - Photo Gallery
- ✅ 9+ images in a CSS Grid layout
- ✅ Uses: `display: grid`, `grid-template-columns`, `grid-gap`
- ✅ Some images span multiple columns/rows using `grid-column: span 2`
- ✅ Responsive design that changes column count

### 2. **product-grid.html** - Auto-fit Product Grid
- ✅ 12 product cards that reflow automatically
- ✅ Uses: `repeat(auto-fit, minmax(250px, 1fr))`
- ✅ Grid automatically adjusts number of columns based on screen size
- ✅ No media queries needed for basic responsiveness

### 3. **dashboard.html** - Dashboard Layout (Bonus)
- ✅ Complete dashboard with header, sidebar, and main content
- ✅ Uses: `grid-template-areas`, `grid-template-columns`, `grid-template-rows`
- ✅ Named grid areas for clean layout structure
- ✅ Nested grids for stats and content sections

## CSS Grid Properties Used:

- ✅ `display: grid`
- ✅ `grid-template-columns`
- ✅ `grid-template-rows`
- ✅ `grid-template-areas`
- ✅ `grid-gap` (spacing between items)
- ✅ `grid-column: span 2` (spanning multiple columns)
- ✅ `grid-row: span 2` (spanning multiple rows)
- ✅ `repeat(auto-fit, minmax())` (responsive without media queries)

## Key Concepts Learned:

1. **Basic Grid Layout**: Fixed columns with gap
2. **Auto-fit Grid**: Automatically adjusts columns based on available space
3. **Grid Areas**: Named areas for complex layouts
4. **Spanning**: Making items take multiple grid cells
5. **Responsive Grids**: Grids that adapt to screen size

## How to View:

Open each HTML file in your browser:

- `product-grid.html` - Auto-fitting product store
